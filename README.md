# E-Commerce React.js Project

This is a modern e-commerce frontend built with React.js. It features a clean UI, product catalog, shopping cart, and user authentication.

## Features

- Product listing and categories
- Product details page
- Shopping cart functionality
- User login and signup
- Responsive design
- Newsletter subscription
- Popular and new collections
- Footer and navigation bar

## Folder Structure

```
src/
  Components/
    Assets/           # Images and product data
    Breadcrums/       # Breadcrumb navigation
    CartItems/        # Cart item display
    DescriptionBox/   # Product description
    Footer/           # Footer section
    Hero/             # Hero banner
    Item/             # Product item component
    Navbar/           # Navigation bar
    NewCollections/   # New product collections
    NewsLetter/       # Newsletter subscription
    Offers/           # Offers section
    Popular/          # Popular products
    ProductDisplay/   # Product display page
    RelatedProducts/  # Related products
  Context/
    ShopContext.jsx   # React context for shop state
  Pages/
    Cart.jsx          # Cart page
    LoginSignup.jsx   # Login and signup page
    Product.jsx       # Product details page
    Shop.jsx          # Main shop page
    ShopCategory.jsx  # Category page
```

## Getting Started

1. **Install dependencies:**
   ```powershell
   npm install
   ```

2. **Start the development server:**
   ```powershell
   npm start
   ```

3. **Open in browser:**
   Visit `http://localhost:3000`

## Customization

- Add products and images in `src/Components/Assets/`
- Update product data in `data.js`
- Modify styles in corresponding `.css` files
